root changed the contract of service `weekly-memo` (v4 -> v5). Read it, and follow the new criteria from the next request on:
- acceptance removed: C10: A period or loose time reference without a specific deadline day (for example "demo week", "this week", "next week") is not a deadline: the Due value for it is none. A deadline tied to a named day or a dated event is converted to an ISO date (for example "before Friday", "the day before the freeze starts").
+ acceptance added: C12: A bare period or loose time reference without a deadline day (for example "demo week", "this week", "next week", "Jo's first week") is not a deadline: the Due value for it is none. "End of <week>" (for example "by end of next week") means the Friday of that week, as an ISO date, converted using the meeting date. A deadline tied to a named day or a dated event is converted to an ISO date (for example "before Friday", "the day before the freeze starts").
+ acceptance added: C13: A statement that something stays unchanged or as it is (for example "Marta will keep the agenda as sent"), where nobody has anything to do, is not an action item: it gets no row in the action table.
Acceptance criteria now:
C1: Uses only the requested notes file and covers that meeting only.
C2: At most 400 words as counted by read.
C3: Has a Decisions section listing every decision made in the meeting, each in one line.
C4: Has an action table with exactly the columns Owner | Action | Due, with one row for every task that someone was given or said they would do (explicit ACTION lines and informal commitments), and no row for anything else.
C6: Every statement is traceable to the notes file; where owner or date is unclear or missing, the memo says so briefly instead of guessing.
C7: The checker's report shows every criterion met (criteria met: n of m with n = m), and the writer applied every required change.
C8: The memo's very first line is a single line starting with "Summary:" that sums up the meeting in one sentence; it is followed by the Decisions section, and then the action table (in this order: Summary, Decisions, actions). No title heading before the Summary line. (not confirmed)
C11: Every Due value is an ISO date (YYYY-MM-DD) or the word none. A deadline given as a named day, a date or a dated event ("by Oct 9", "before Friday", "by Thursday", "for Oct 14", "the day before the freeze starts") is converted to an ISO date using the meeting date; "before Friday" or "by Friday" means that Friday itself (for the 2026-10-05 meeting, Friday is 2026-10-09). Use none when the notes give no date or deadline, or only a loose period (see the next criterion). (not confirmed)
C12: A bare period or loose time reference without a deadline day (for example "demo week", "this week", "next week", "Jo's first week") is not a deadline: the Due value for it is none. "End of <week>" (for example "by end of next week") means the Friday of that week, as an ISO date, converted using the meeting date. A deadline tied to a named day or a dated event is converted to an ISO date (for example "before Friday", "the day before the freeze starts"). (not confirmed)
C13: A statement that something stays unchanged or as it is (for example "Marta will keep the agenda as sent"), where nobody has anything to do, is not an action item: it gets no row in the action table. (not confirmed)
