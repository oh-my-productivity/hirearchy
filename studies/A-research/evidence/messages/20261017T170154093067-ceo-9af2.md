## Goal
Gather comprehensive, sourced, current (as of 2026-10-17) facts on self-hosted note-taking / knowledge-base apps for a competitor analysis. Research the following candidates and verify their current relevance/activity, dropping any that are abandoned and adding any notable alternatives you discover: Joplin, TriliumNext (successor to Trilium), Standard Notes, Memos, Outline, SiYuan, AFFiNE, AppFlowy, BookStack, Docmost, HedgeDoc, SilverBullet, Notesnook, Logseq. Aim to shortlist 6-8 of the most relevant apps.

For each app in the final shortlist, gather:
1. **Landscape & project health**: GitHub stars, latest release version + date, commit activity, maintainer/governance model, license (exact SPDX), any paid-tier gating of self-hosted features.
2. **Feature matrix**: editor type (WYSIWYG/Markdown/block), organization (folders/tags/notebooks/wikis), full-text search (quality/limits), backlinks/graph, E2EE (yes/no and implementation), real-time collaboration, mobile apps (iOS/Android), plugins/API, import formats, export formats.
3. **Self-hosting**: deployment method (Docker/binary/etc.), dependencies, resource requirements, backup strategy, auth/SSO options, release cadence.

Write findings as a structured markdown file at `ceo/researcher/work/research_notes.md`. Every factual claim must include a source URL in brackets. Flag anything you cannot verify as UNVERIFIED.

- research_notes.md exists at ceo/researcher/work/research_notes.md

- Unverified claims explicitly flagged as UNVERIFIED
