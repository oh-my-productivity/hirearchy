usage: orgmcp obs [-h] {now,trace,metrics,events} ...

positional arguments:
  {now,trace,metrics,events}
    now                 what is happening right now: scheduler, runs, queue, what waits on you,
                        recent errors
    trace               one request (a root task) as a tree of messages, runs, tool calls and
                        refusals, with totals
    metrics             runs, failures, refusals and latency percentiles over a time window
    events              the merged raw event stream, filtered

options:
  -h, --help            show this help message and exit
